病害發生的三個條件5-1

三個條件同時存在才會發病，破壞其中一個就能防治。

  • 主因：細菌、病毒等病原
  • 誘因：細雨綿綿 → 真菌；乾燥 → 白粉病；氮肥太多 → 稻熱病
  • 素因：作物本身的遺傳（茄科易得青枯病）

植物保護：狹義＝發生後防治；廣義＝發生前就預防（育種、檢疫）。

非傳染性 vs 傳染性病害5-2

非傳染性（非寄生性）＝環境造成
  • 低溫 → 鳳梨黑心病
  • 缺氧 → 馬鈴薯黑心病
  • 缺硼 → 木瓜塊腫病
  • 水分過多 → 馬鈴薯日燒病
  • 二氧化硫 → 葉綠素消失
傳染性（寄生性）＝生物造成真菌、細菌、病毒、菌質、黏菌、線蟲、蟎類、寄生性顯花植物

病徵分：局部性（葉斑、腐爛、根瘤）、系統性（黃化、矮化、嵌紋、簇葉）

病原怎麼傳播？5-2

認識昆蟲5-2

  • 節肢動物門・昆蟲綱：身體分頭、胸、腹
  • 觸角 1 對、足 3 對、翅 2 對都在胸部
  • 外骨骼含幾丁質 → 要脫皮才能長大
  • 用氣孔、氣管呼吸；馬氏管排泄

口器：怎麼吃，決定用什麼藥5-2

昆蟲的變態5-2

完全變態有蛹期
卵→幼蟲→蛹→成蟲
蛾、蝶、蜂、蠅、蚊、金龜子、天牛
不完全變態沒有蛹
卵→若蟲→成蟲
蝗蟲、椿象、蚜蟲、薊馬、蟬（陸生）
半變態水生幼體
卵→稚蟲→成蟲
蜻蜓
無變態
卵→仔蟲→成蟲
衣魚、跳蟲

翅：鞘翅目＝甲蟲｜半翅目＝椿象｜鱗翅目＝蛾蝶｜雙翅目＝果實蠅｜同翅目＝蚜蟲、介殼蟲

食性與趨性5-2

食性單食：負泥蟲（稻）｜寡食：紋白蝶、小菜蛾（十字花科）｜多食：蝗蟲、夜盜蟲
趨性趨光：蛾（誘蛾燈）｜趨化：性費洛蒙、甲基丁香油引誘果實蠅｜負趨化：樟腦丸

昆蟲適溫約 26℃；38℃ 以上夏眠，15℃ 以下冬眠。

雜草5-2

水生雜草鴨舌草、野茨菰、蘋草、紅骨草、螢藺
濕生雜草水稗、牛毛氈、球花蒿草
乾生雜草牛筋草、香附子、狗牙根、野莧、藿香薊
禾本科稗草、牛筋草、狗牙根莎草科香附子、螢藺
菊科藿香薊、咸豐草、昭和草莧科滿天星、野莧
澤瀉科野茨菰雨久花科鴨舌草
茄科龍葵石竹科鵝兒腸

危害：搶水搶肥搶光、當病蟲的中間寄主、分泌毒素。絕對雜草（車前草）vs 相對雜草（稻田裡的蔬菜）。

病害防治四原則5-3

1禦病不讓病原進來
檢疫、隔離苗圃
2抗病種抗病品種
最經濟有效
3除病除去病原
拔除病株、清園
4治病用農藥保護
最有效

系統性病害要拔除病株；病毒病沒有藥醫，要殺媒介昆蟲、剷除中間寄主。

蟲害五大防治法5-3

生物防治：誰打誰？5-3

性費洛蒙是無毒的，用來誘殺雄蟲或干擾交配。有機防治：苦楝、苦茶粕、除蟲菊、波爾多液、草木灰。

雜草防除與殺草劑5-3

農業防除（輪作、深水灌溉、覆蓋）｜物理防除（手拔、鐮刀割）｜生物防除（放牧鴨鵝）｜化學防除（殺草劑）

殺草劑選擇性作用方式重點
2,4-D選擇性輸導・生長素型殺闊葉雜草；應用最廣
巴拉刈（克蕪蹤）非選擇接觸型綠色植物都殺
嘉磷塞（年年春）非選擇輸導型萌後處理
丁基拉草（馬上除）選擇性萌前處理水田稗草、螢藺
草霸王（本達隆）選擇性水田萌後對禾本科無害

接觸型＝碰到才有效｜輸導型＝吸收後移到全株（較省工）

殺蟲劑：怎麼殺死害蟲？5-3

胃毒劑吃下去才中毒 → 咀嚼式口器（鱗翅目幼蟲、蝗蟲）
觸殺劑碰到就死（封住氣孔）；除蟲菊、魚藤精、石灰硫黃合劑
滲透劑又稱官能性，藥進入植物體 → 刺吸式口器（蚜蟲）
燻蒸劑氣體殺蟲；溴化甲烷
引誘劑甲基丁香油（引誘果實蠅雄蟲）
忌避劑把蟲趕走；樟腦丸
殺菌劑：預防劑（保護）發病前用：硫黃劑、銅劑（波爾多液）
殺菌劑：治療劑（直接殺菌）發病初期用：抗生素、免賴得

植物生長調節劑5-3

生長素IAA、IBA、NAA、2,4-D扦插發根、頂芽優勢、果實肥大
激勃素GA莖伸長、打破休眠、單偽結果（無籽）
細胞分裂素Kinetin、BA、玉米素細胞分裂、打破頂芽優勢、延遲老化
離層酸ABA葉果脫落、誘導休眠、抑制萌芽
乙烯C₂H₄（氣體）催熟（香蕉、木瓜）、胡瓜多開雌花
生長抑制劑矮壯素 CCC、MH、秋水仙素矮化抗倒伏；秋水仙素 → 無籽西瓜

安全使用農藥5-3

  • 噴藥要逆風倒退（不是逆風前進）
  • LD50＝半數致死量，數字越小越毒
  • 同一種藥一直用 → 抗藥性，要輪流用藥
  • 劑型：SL 溶液、EC 乳劑、DP 粉劑、WP 可濕性粉劑（先調成糊）
  • 臺灣河水偏鹼，稀釋可加少量食醋

氣象危害5-4

日照不足黃化、徒長、不開花 → 疏苗、修枝、種耐陰作物
日照過多樹木皮燒、果實曬傷 → 遮陰；鳳梨、花椰菜束葉防曬
低溫、霜凍害、霜裂 → 燻煙、灑水、風扇、塑膠布覆蓋
風抗風品種、支柱、防風林
空氣污染SO₂ → 葉綠素消失｜氟化物 → 香蕉葉緣枯｜臭氧 → 洋蔥葉尖焦枯
濕度太高病原多 → 溫室原則「頭乾足濕」、通風、無滴膜
成霜條件：晴朗無風、有水氣、逆溫層、低溫。防霜就是破壞它（燒火炬、開風扇讓空氣對流）。

土壤危害5-4

  • 氮易流失 → 分次施；磷會被土壤固定 → 少次多量
  • 高山常缺鈣（施碳酸鈣）；海邊常缺鎂（施碳酸鎂）
  • 重金屬：鉛 Pb、鎘 Cd、鉻 Cr、汞 Hg、砷 As
  • 改良：翻土、客土、植物修復（蜈蚣草吸砷、堇菜吸鉛鎘）
