# 易霖工作用

高職園藝・農業群教學用的網頁，用 GitHub Pages 發布。

網址：https://teacher-liujikan.github.io/yilin-work/

| 資料夾 | 內容 |
| --- | --- |
| `agri-quest/` | 農業概論 第一次聯合模擬考 闖關測驗（50 題・5 關） |
| `agri-review/` | 農業概論 第一次聯合模擬考 學生自我檢討 |
| `agri-ch3/` | 農業概論 第三章 作物生產 總複習（教學＋QR 小測驗） |
| `agri-ch4/` | 農業概論 第四章 土壤肥料 總複習（教學＋QR 小測驗） |

## 規則

- 每個網頁放在自己的資料夾，檔名用 `index.html`，網址就是 `https://teacher-liujikan.github.io/yilin-work/<資料夾>/`。
- 新增網頁時，同時在根目錄的 `index.html` 加一筆連結。
- 每個網頁的 localStorage KEY 要不一樣，避免作答紀錄互相覆蓋。
- 網頁裡 QR code 的備用網址要改成該網頁自己的網址。
